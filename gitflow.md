
# Flujo de trabajo Gitflow

Para organizar el desarrollo del sistema de control de rescate y adopción animal se utiliza Gitflow como referencia para administrar las ramas del repositorio.

## Ramas utilizadas

- **main:** contiene la versión estable del proyecto.
- **develop:** reúne los cambios que se preparan durante el desarrollo.
- **feature/diagramas-uml:** se utiliza para trabajar en los diagramas UML.
- **feature/documentacion:** se utiliza para organizar y actualizar la documentación.

## Forma de trabajo

Las tareas se separan en ramas para mantener el trabajo organizado. Una vez revisados los cambios, las ramas de funcionalidad pueden integrarse en develop. Cuando el proyecto esté preparado para una entrega estable, los cambios aprobados podrán integrarse en main.

## Ventajas

Este flujo permite separar las tareas, conservar un historial de cambios y reducir el riesgo de modificar directamente la versión estable del proyecto.
