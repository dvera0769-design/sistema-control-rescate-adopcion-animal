# Arquitectura lógica del sistema

El sistema de control de rescate y adopción animal se propone mediante una arquitectura de tres capas para mantener organizadas sus funciones.

## Capa de presentación

Es la parte que utilizarían los usuarios para registrar animales, consultar información y gestionar solicitudes de adopción.

## Capa de lógica de negocio

Contiene las reglas que permiten validar los registros, controlar las solicitudes y organizar los procesos de rescate y adopción.

## Capa de acceso a datos

Se encarga de guardar, consultar y actualizar los datos de los animales, usuarios, rescates e historiales médicos.

## Ventajas

Esta organización permite separar las responsabilidades del sistema, facilita el mantenimiento y ayuda a incorporar nuevas funciones cuando sean necesarias.
